# Personal Expense Analytics

## Project Overview
This project analyzes personal expenses and visualizes spending patterns using Python.

## Tools Used
- Google Colab
- Python
- Pandas
- Matplotlib

## Features
- Calculate total expenses
- Analyze expenses by category
- Identify highest spending category
- Generate Pie Chart
- Generate Bar Chart

## Dataset
Contains expense records with:
- Date
- Category
- Amount

## Output
- Expense Summary
- Expense Distribution Pie Chart
- Expense Category Bar Chart
